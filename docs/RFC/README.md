# RFC Index

This directory contains Request for Comments (RFC) documents that describe proposed or evolving
technical strategies and design decisions. RFCs are intentionally more exploratory than ADRs and
may describe:

1. current implementation state and empirical validation evidence,
2. proposed target architecture and instrumentation contracts,
3. phased rollout plans and verification criteria,
4. and explicit scope boundaries (e.g., "mechanism is frozen-by-default").

When an RFC becomes a stable architectural commitment, it should be translated into an ADR under
`docs/ADR/`.
